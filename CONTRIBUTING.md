# Contributing to APIxray

First off, thank you for considering contributing to APIxray! It's people like you that make APIxray such a great tool for developers. 

## Code of Conduct

By participating in this project, you are expected to uphold our Code of Conduct. Please be respectful and considerate to others.

## How Can I Contribute?

### Reporting Bugs

This section guides you through submitting a bug report for APIxray. Following these guidelines helps maintainers and the community understand your report, reproduce the behavior, and find related reports.

1. **Check if the bug has already been reported.** Search the issues to see if it's already there.
2. **Use a clear and descriptive title** for the issue to identify the problem.
3. **Describe the exact steps** which reproduce the problem in as many details as possible.
4. **Describe the behavior you observed** after following the steps and point out what exactly is the problem with that behavior.

### Suggesting Enhancements

This section guides you through submitting an enhancement suggestion for APIxray, including completely new features and minor improvements to existing functionality.

1. **Use a clear and descriptive title** for the issue to identify the suggestion.
2. **Provide a step-by-step description of the suggested enhancement** in as many details as possible.
3. **Explain why this enhancement would be useful** to most APIxray users.

### Pull Requests

The process described here has several goals:

- Maintain APIxray's quality
- Fix problems that are important to users
- Enable a sustainable system for APIxray's maintainers to review contributions

Steps to submit a PR:

1. Fork the repository and create your branch from `main`.
2. If you've added code that should be tested, add tests.
3. If you've changed APIs, update the documentation.
4. Ensure the test suite passes.
5. Make sure your code lints.
6. Issue that pull request!

## Setting up your development environment

1. Clone the repository
2. Install dependencies: `npm install`
3. Run the application in development mode: `npm start`
4. To build the application, use `npm run make`

Thanks again for your contribution!
